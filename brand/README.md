# Лаборатория ЭкоКарьеры

The approved four-stroke symbol is `logo/svg/ecocareer-symbol.svg`. Keep its geometry, round caps and four original colors unchanged. The symbol colors are a logo exception to the interface palette.

Use the two-line Inter lockup on desktop: Лаборатория above ЭкоКарьеры, symbol on the left. Mobile uses the symbol only. No slogan. The frontend renders live Inter text next to the canonical symbol so Cyrillic and font loading stay consistent.

Interface palette: black `#000000`, green `#70E852`, light green `#C9FFBF`, white `#FFFFFF`. Dark green `#246B20` is for readable links, secondary controls and focus. All typography is Inter with Cyrillic. Existing font/color role aliases remain for compatibility, not as alternative brand directions.

`brand/` is canonical; matching served assets live in `web/public/brand/`. The favicon is also copied to `web/public/favicon.ico`. `colors/tokens.css` mirrors `web/src/styles/brand-tokens.css`. Historical explorations are not active branding.
